# 佣兵合同大厅：流亡佣兵团（无地国）的收入来源。
# 无地国没有税收——改革 desc 承诺"依靠佣兵合同维持自身"，机制上此前只有
# 人力池（给兵）没有合同收入（给钱）。仿原版海盗兄弟会改革建筑
# （capital_country_modifier = { monthly_gold_income = 20 }）先例：
# 外国建筑给所有国国家级月度金收入。数值刻意极小（每座 +1/月）：
# 用户指定，象征性合同抽成，多建多收。

# 贸易容量 0.5：merchant_capacity_from_building（location 级、归建筑所有者），
# 与军团港同级——合同大厅人来人往，顺带撮合一点买卖。

# 团练所：士兵阶层专属建筑。授予“团练自治”特权后，阶层可在乡村与城镇营建，
# 作为地方军事据点（人力/征召/阶层力量），代价是本地士兵食物消费上升。
# 岗位方案（A：岗位给农民）：
# · EU5 建筑必须有 employment_size 岗位才能生效（原版 453 个建筑全部带岗位，
#   无岗位建筑经游戏实测不产生任何效果）。
# · 岗位若给士兵（pop_type = soldiers），空缺岗位会以最高晋升权重（SOLDIERS=40）
#   吸引农民晋升填岗，形成"士兵阶层永动机"，永久抵消退伍安置/老兵返乡的阶层
#   回落环节，与 mod 核心循环冲突。
# · 故团练所雇佣本地农民当杂役（pop_type = peasants，参照原版
#   peasants_training_grounds 范本），岗位规模 estate_manpower_employment = 0.1
#   （约百人级）。"士兵阶层力量"修正来自军事据点的象征与控制力，而非雇佣士兵；
#   团练所不直接制造士兵 POP，阶层回落循环不受影响。
