# 刀锋与王座 / Blades and Thrones

Europa Universalis V（1.3.x）军事政治机制模组：**军队忠诚、佣兵军团国、士兵阶层、老兵与复员、军事政变与军人集团**——把"军队"从单纯的兵力数字变成一股有欲望、会要价、能夺权的政治力量。

## 核心机制

### 🏴 无地军团国体系
被吞并国家的残军、哗变的雇佣兵，会变成一支**没有领土的军队国家**：
- **流亡者**——国家灭亡后残军的延续，可复国、可安家、可受封
- **佣兵军团**——主动外派的雇佣兵团，逐利、索饷、可能撕毁条约独立
- **自由军团**——撕毁臣属条约后的独立佣兵国（Free Company）
- **藩镇**——获得地盘后的军阀形态，听调不听宣

### ⚔️ 军队忠诚与军事政变
- 常备军有自己的**忠诚度**：欠饷、战败、阶层不满都会侵蚀它
- 忠诚崩溃 → 哗变 → **军事政变** → **军人集团统治灾难**（稳定度博弈：还政 / 制度化 / 清洗 / 铁腕巩固）
- 军政府还政后有永久修正奖励（每个国家一生一次）

### 🪖 士兵阶层
- 新增**士兵**阶层：只由士兵 POP 支持，提供陆军传统、兵员与补充
- **军饷体系**：国库每月按编制发放现金俸禄（与维护滑条独立）；欠饷 → 满意度崩溃 → 哗变风险
- 阶层特权：团练自治（团练所建筑）、国家佣兵合同等

### 📜 军制与国家
- 军制法律：常备军 / 雇佣兵联盟 / 混合军制 / 征召军制
- 时代联动：早期（1337 传统时代）佣兵与征召为黄金时代，晚期常备军崛起
- 老兵体系：退伍安置、欠饷遣散、精锐保留与制度化

### 🔥 雇佣兵夺舍灾难
雇佣兵兵力超过可控军力时触发：叛军进度由威胁比率动态驱动，胜利后按兵力三分支（夺舍流亡 / 和解自立 / 佣兵剿灭）。

## 安装

1. 下载本仓库 ZIP（绿色 **Code** → **Download ZIP**）并解压
2. 把解压出的文件夹改名为 `刀锋与王座`
3. 放入 `文档\Paradox Interactive\Europa Universalis V\mod\` 目录
4. 启动游戏，在启动器的 Mods 列表中启用"刀锋与王座"（文件夹内含 `.metadata`，启动器自动识别）
5. **开始新档**（本 mod 不保证旧档兼容）

## 兼容性

- 游戏版本：**1.3.x**（官方中文/英文均可）
- 与 **Anno 1644（甲申年·1644）** 兼容（国名模板、行省附庸等共享文件已对齐两版）
- 不依赖其他 mod 即可运行

- 本 mod 全程基于 EU5 实测开发，所有机制均有 vanilla/1644 先例支撑
